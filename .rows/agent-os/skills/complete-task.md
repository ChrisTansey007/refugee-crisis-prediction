# Skill: Complete Task

Use this skill when your implementation work is done and the task is ready to move toward review and close-out.

## Purpose

Move from finished work to verified, reviewable, pushed repo state without skipping the push gate or the handoff requirement.

## Steps

1. Re-check the task acceptance criteria and verification requirements.
2. Update documentation, evidence, and the task file as needed.
3. Run the strongest relevant validation you can locally.
4. Move the task to `review/` unless an independent reviewer has already approved completion.
5. Run [`session-close.md`](./session-close.md) for commit, push, handoff, and worker-state updates.
6. Only move a task to `done/` after independent review and push confirmation.
